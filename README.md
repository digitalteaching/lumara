# Lernwelt RPG

Ein HTML-Lernspiel im Stil alter Handheld-Konsolen. Ein Kind wählt ein Wesen, erkundet eine geheimnisvolle Welt und besteht Duelle mit Vokabel- und Grammatikaufgaben. Dafür bekommt es Punkte, und sein Wesen entwickelt sich weiter. Die Inhalte lassen sich je nach Fach austauschen. Die erste Version ist für Jahrgang 6 Englisch.
